# 1.0.0-alpha.27 — Smaller controls, safer saves

- Touch controls take up less of the screen. The default arrows, sword, jump,
  dash and pause buttons are about 15% smaller each, so the two clusters now
  cover roughly 18% of the view instead of a quarter. Every button still
  measures at least 60 dp on a 320-dp-tall phone. Pick Large in Settings →
  Control size to get close to the old footprint.
- Your progress is safer. If the live save file is ever unreadable and the
  game recovers from its backup, saving again no longer overwrites that
  readable backup with the broken file.

## VERIFIED engineering evidence — September 10

- Analyzer clean; 645 tests pass / 2 existing manual skips (one new test:
  default touch clusters cover <= 19% of the view). The only changed existing
  assertion is the touch-target floor (44 → 38 view units, i.e. >= 60 dp on
  any phone >= 320 dp tall), a deliberate spec change documented in
  progress.md. No other test or check was edited.
- Web harness screenshots before the change confirmed the owner-audit finding
  (2026-09-06): the bottom third of the playfield sat behind translucent
  white buttons.
- Save-backup fix: see `docs/save-backup-recovery-sep09.md` (seven regressions).
